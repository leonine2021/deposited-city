# 界：析出的城市 · Boundary: The Deposited City

The QR-code companion site for architect Wenlu Guo's exhibition.
A single vertical scroll: prologue, seven works chosen by the artist (few and chosen, so the walk never tires the eye on a screen) in one flowing sequence (the bar names the zone of the work on screen; each zone's wall text follows its first work), the synthesis, the coda and the exit. One screen, one work: figurative works are shown whole, as large as the screen allows, and never up close; abstract works are shown only as the artist's own crop, filling the screen under a line of text, and never whole.

Live: https://leonine2021.github.io/deposited-city/

## Develop

```sh
npm install
npm run dev
```

Pushing to `main` builds the site and deploys it to GitHub Pages (`.github/workflows/deploy.yml`).

## Content

- `src/content.js` holds every visitor-facing text, in Chinese and English.
- `public/works/` holds the artwork images, generated by `scripts/prepare_images.py` (needs `pillow`, `numpy`) from the high-resolution scans in `../works/`. The script maps each scan to its work number and rotation; works without a sharp scan yet get a flat placeholder; the abstract works get a `-detail` image (plus thumbnail) from the artist's crop in `../works/crops/`, the only image of them the site shows.
- `src/scenes.js` holds the scroll scenes, one per beat; `src/main.js` sets the order of beats (the choreography).
